Cómo usar este explorador

1. Seleccionar un grupo

Usa el menú lateral para elegir uno de los 17 grupos de simetría.

2. Aplicar operaciones

Haz clic en los botones de simetría para aplicar rotaciones, reflexiones, traslaciones o glides.

3. Observar los resultados

Compara el patrón original con el transformado. Si coinciden (correlación ≈ 100%), ¡la operación es una simetría del grupo!

4. Experimentar

Combina múltiples operaciones y observa cómo se relacionan. Usa el botón Reset para empezar de nuevo.
